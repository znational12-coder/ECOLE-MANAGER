École Manager — mises à jour hors ligne

1. Copier le nouvel installateur dans :
   %APPDATA%\Ecole Manager\updates\

2. Créer ou remplacer manifest.json, par exemple :
   {"version":"1.1.1","installer":"École Manager-Setup-1.1.1.exe"}

3. Dans l’application : Maintenance → Vérifier une mise à jour hors ligne.

La mise à jour ne nécessite aucune connexion Internet. Faire une sauvegarde avant une mise à niveau majeure.
