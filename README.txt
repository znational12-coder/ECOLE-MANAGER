École Manager - version Windows hors ligne

Les données de l'école sont stockées localement dans le dossier de données utilisateur Windows de l'application.
Aucune connexion Internet n'est requise pour les fonctions de gestion scolaire.

Important : la fonctionnalité IA Gemini de la version web a été retirée de l'édition hors ligne afin de garantir l'absence d'appels réseau externes.
